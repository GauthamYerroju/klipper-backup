# Klipper-Backup 💾 
Klipper backup script for manual or automated GitHub backups 

This backup is provided by [Klipper-Backup](https://github.com/Staubgeborener/klipper-backup).

## Set up CB1

* Get the Minimal image from https://github.com/bigtreetech/CB1/
* Flash it to an SD card
* Configure /boot/{system.cfg,armbianEnv.cfg} (instructions in the CB1 repo)
* Put SD card into CB1 and run through Armbian's first-boot setup
* Clone this repo and run ./setup.sh
